# 对话变连环画 · conversation-to-comic

将会议、访谈、播客、群聊或已有文章改编成多人竖版连环画。保留发言人的真实贡献，支持文章共创、人物参考、分镜与局部修订。

## 使用

将整个目录交给能读取文件的 agent，并说：

> 请阅读 SKILL.md，按说明把这些对话材料与人物参考图改编成竖版连环画。

支持 skills 的环境可将完整文件夹放入该环境的技能目录。Codex 的个人目录通常为 `~/.codex/skills/`，也可由 `CODEX_HOME` 指定。安装后调用：

> 请使用 $conversation-to-comic，把这份会议逐字稿和人物照片改编成幽默、易懂的竖版连环画。

## 输入与输出

- 输入：逐字稿或文章；可选的人物照片/头像、姓名勘误、读者和风格偏好。
- 输出：连环画位图、分镜与提示词；复杂项目附交接笔记。文章和公众号 HTML 按需提供。
- 照片缺失时使用明确的符号角色，不冒充真人肖像。

## 工具要求与范围

这是一套工作流程指令，不包含图像模型、API 密钥或自动出图程序。实际成图需要 agent 可调用的图像生成/编辑能力；没有该能力时只能完成脚本与提示词。人物参考、文字准确性、分辨率和局部编辑效果依赖所用工具，不保证所有 agent 同样表现。

完整目录包含 SKILL.md、agents/openai.yaml 和 references 下的两个指南。请分享整个目录或 ZIP，单独 SKILL.md 会缺少配套引用。包内不含原始会议材料和私人照片。

## 当前验证范围

流程来自一次真实会议文章与漫画制作；封装后的 skill 已做独立静态挑刺审查及基础结构、引用检查。尚未完成由陌生 agent 独立执行完整生成与修订的端到端验证。官方 Python 校验器在本地因缺少 PyYAML 未运行成功，基础检查不是它的完整替代。

## 怎样提供有用反馈

请附所用版本或包文件名、agent/图像工具、简短输入说明、期待结果、实际结果、卡住的步骤；必要时提供脱敏截图，不上传未获授权的素材。

尤其有价值的反馈：是否能找到配套文件；姓名/发言是否归属正确；手机上能否阅读；只改头像时其他内容是否漂移；换 agent 后能否凭项目笔记接续；用了多少轮生成与人工修订。

## 三个小型试用场景

1. 三位虚构发言人，一人展示、一人质疑、一人总结。给两张头像、一人无头像。检查三人贡献、观点分歧与无照片角色是否保留。
2. 给已完成漫画与一个新头像，说“只替换这个人，其余不变”。检查所有出场位置及无关区域是否保持。
3. 在没有图像工具的 agent 中使用。检查是否如实交付分镜/提示词，而不声称生成了图片。

这些是待执行的试用场景，不是已通过的测试。
