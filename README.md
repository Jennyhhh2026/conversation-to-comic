# 对话变连环画

**把会议、访谈、播客和文章，变成有故事、有幽默、有洞察的竖版连环画。**

让做事的人展示自己的实践，让提问的人留下自己的贡献，让值得记住的对话被更多人看见。

## 从对话到漫画

**提炼对话 → 核对事实 → 建立角色 → 编排分镜 → 生成漫画 → 局部修订**

- **有依据：**区分现场事实、嘉宾自述与作者洞察，不为金句编造经历。
- **有角色：**参考照片、动物或物品头像，建立一致的人物形象。
- **有故事：**把观点变成动作和场景，用现场反差与细节制造幽默。
- **能接续：**保留分镜、提示词和项目笔记，方便后续 agent 继续修改。

## 如何使用

将完整的 [`conversation-to-comic`](./conversation-to-comic/) 文件夹交给能够读取文件的 AI agent，并附上对话或文章、可选人物参考图：

> 请阅读 conversation-to-comic/SKILL.md，按说明把这些对话材料和人物参考图改编成幽默、易懂的竖版连环画。

在已安装该 skill 的环境中，也可以这样说：

> 请使用 $conversation-to-comic，把这份会议逐字稿和人物照片改编成竖版连环画，保留各位发言人的贡献与现场趣味。

## 你需要准备什么

一份会议逐字稿、访谈记录或文章，就可以开始。人物照片或头像、姓名勘误、读者和风格偏好，会帮助 agent 做得更贴切。

这是一套工作流程指令，不包含图像模型或 API 密钥。实际出图需要 agent 具备图像生成与编辑能力；没有出图工具时，可完成分镜与提示词。
