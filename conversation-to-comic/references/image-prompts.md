# 图像提示词模板

根据实际工具改写，不把这里的字段当 API 参数。用当前已确认的人名和台词替换变量。避免把整篇文章塞入出图提示词。

## 人物设定图（仅参考超限或需要统一造型时）

用途：为后续多人漫画建立一致角色。
输入图：按编号逐个写明姓名、真人/头像类型及辨识特征。
要求：每人独立清楚、姓名准确、统一画风；动物/物品头像保留原类型；背影参考不编造可辨认的正脸；不增添未经提供的职业或道具事实。
画风：采用用户选定的媒介、配色、线条与比例。
输出：一张干净、可继续作为参考的角色图。

## 完整连环画

用途：根据真实对话改编的竖版连环画，手机连续阅读。
尺寸：填写当前工具可实现的目标尺寸/比例；文本密度按此预算。
输入图：
- 图1：角色设定参考或已认可底图，明确角色。
- 图2等：具体人物参考，逐一映射，不遗漏。
角色表：准确姓名、头像类型、服饰发型、出现幕号。
视觉：统一画风与主色、留白、清晰中文；连续漫画场景，不做摘要海报。
标题：逐字给出。
逐幕：幕号 / 人物 / 动作与关系 / 气泡逐字文本 / 姓名标签。
约束：不虚构业绩或活动事实；不擅自把线上交流画成真实线下合影；无照片者用符号；全图完整不裁切。
页尾：按需标注“根据现场交流改编”。

## “只补几个人，其余不变”

编辑图1；图2起为新增角色参考。
仅改以下位置：
- 第A幕，标注某姓名的窗格内部：用图2的同风格肖像替换原占位图。
- 第B幕，同名角色第二次出现处：同样替换。
- 第C幕群像，标注某姓名的窗格：用图3头像替换。
逐项保持：姓名标签、气泡文本、窗格边界、其他角色、分镜数、配色、标题、结尾、尺寸比例。
不要修无关错字或重新安排布局。输出完整长图。

## 生成后的对照

核对实际图中每个名字而不只看提示词：常见问题包括同音错字、相似汉字、拉丁字母误写、小窗格重复、气泡串给别人。对照所有角色出现位置，而不只检查最大的肖像。

字太小：先缩减气泡内容或拆成连续页，不继续堆叠“更高清”要求。角色漂移：用已认可的设定/上一版作参考，并限制修改区域。
